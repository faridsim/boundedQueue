# Boundflow

A bounded thread-safe FIFO queue implemented in modern C++20.

## Project Status

Active development

The project is currently evolving toward a more complete concurrency
library with stronger verification, richer APIs, and additional
performance evaluation.

The current implementation focuses on:

- bounded FIFO behaviour;
- blocking and immediate operations;
- explicit shutdown semantics;
- state-based concurrency testing;
- documented design decisions
